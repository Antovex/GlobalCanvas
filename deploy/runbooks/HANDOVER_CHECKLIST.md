# Center Handover Checklist

Use this checklist whenever a center requests full transfer.

- [ ] Source snapshot provided (repository URL + commit/tag)
- [ ] Container image tag/version provided
- [ ] Center-specific compose + `.env` key inventory provided
- [ ] Current database dump delivered
- [ ] Prisma migration history delivered (`prisma/migrations`)
- [ ] Backup/restore runbook delivered
- [ ] Latest restore drill evidence delivered
- [ ] Operational contacts and ownership matrix delivered
- [ ] Credential rotation checklist delivered
- [ ] Acceptance confirmation received from receiving party
