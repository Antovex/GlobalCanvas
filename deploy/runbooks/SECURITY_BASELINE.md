# Security Baseline (Per Center)

Mandatory controls for every center deployment:

- HTTPS termination enabled at reverse proxy.
- Dedicated least-privilege database user and database.
- Separate secrets and credentials per center.
- Secret rotation process documented and rehearsed.
- Access granted by center scope (no broad shared operator access).
- Backup artifacts stored in center-isolated location.
- Incident owner and escalation contact defined per center.
